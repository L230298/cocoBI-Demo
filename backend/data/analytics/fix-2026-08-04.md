### Bug #1：GMV 被识别为"数量"

**根因**：`re.search(r"多少\s*个?", text)` 中 `\s*` 和 `个?` 都可选，"多少" 单独就匹配，永远走不到 GMV 检查分支。

**修复**：调换 if/elif 顺序，让 GMV/销售额等显式业务术语先匹配；移除宽松的 `\s*`；单独加 `多少行` 分支。

### Bug #2：字段缺失静默降级

**根因**：metric="GMV" 但数据集无 amount 字段时，系统用 COUNT(*) 替代（"上周 GMV" 变 "上周数量"）。

**修复**：`_mock_nl2sql` 开头加字段缺失检测，缺 `amount` 时返回 `is_executable=False` + `fallback_message`，orchestrator 转成 fallback 事件给前端。I3 阈值预警缺 `stock` 字段同理。

### Bug #4：归因 SQL 语法错

**根因 1**：`SUM(COUNT(*)) OVER ()` 在 SQLite 中无效（窗口函数不能直接套聚合）。

**根因 2**：用隐式 CROSS JOIN (`FROM t1, t2`) 算 total，连接条件丢失。

**修复**：用嵌套子查询 + 标量子查询分别算 agg 和 total，避开窗口函数。
